# Customer Segmentation & Retention Analytics in Power BI

## Project Overview
This project uses Power BI to analyze customer behavior, customer segments, spending patterns, and retention status. The goal is to help business and marketing teams understand customers and identify opportunities to improve retention.

## Objectives
- Analyze customer demographics.
- Understand customer segments.
- Measure customer retention and churn.
- Examine customer spending and average order value.
- Enable interactive analysis using slicers.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Dashboard Features
- **KPI Cards:** Total Customers, Retention Rate, Churn Rate, Total Spend, and Average Order Value.
- **Charts:** Customer Count by Gender, Customer Count by Age, Customer Count by Segment, and Customer Retention Status.
- **Slicers:** Customer Segment, City, and Purchase Channel.

## Key Findings
- Total customers: 120
- Retained customers: 27
- Churned customers: 54
- Customers at risk: 39
- Retention rate: 22.5%
- Churn rate: 45%

## Business Recommendations
- Identify reasons for customer churn.
- Develop targeted retention campaigns.
- Offer relevant incentives to at-risk customers.
- Use customer segments to personalize marketing activities.
